# Location Information App


## Features
- Requests location permission from the user
- Displays Google Maps centered at the user's current location
- Shows a marker at the user's location
- Displays the current address 
- Allows placing custom markers by tapping the map
- Custom markers show their address when tapped
- Button to clear all custom markers

## Tech Stack
- Kotlin
- Jetpack Compose
- Google Maps Compose
- Google Play Services Location
- Accompanist Permissions
- Geocoder API
